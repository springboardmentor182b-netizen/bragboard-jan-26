# README.png Instructions

## How to Create the README.png Screenshot

To complete the README, you need to add a screenshot of the **Admin Shout-Out Moderation Screen**.

### Steps to Create README.png:

1. **Start the Application**
   - Run the backend server: `cd server && python main.py`
   - Run the frontend: `cd client && npm start`

2. **Navigate to the Moderation Screen**
   - Open http://localhost:3000 in your browser
   - Login with admin credentials
   - Click on "Moderation Queue" in the sidebar

3. **Capture the Screenshot**
   - Make sure the screen shows:
     * The "Moderation Queue" header
     * The filter buttons (Most Recent, Oldest First, All, Pending, Under Review)
     * The table with flagged content
     * The Dismiss and Delete action buttons
   - Take a screenshot using:
     * Windows: `Win + Shift + S`
     * Mac: `Cmd + Shift + 4`
     * Linux: PrtScn or screenshot tool

4. **Save the Screenshot**
   - Save the file as `README.png`
   - Place it in the root directory: `c:\Users\HP\Desktop\bragboard\bragboard-jan-26\README.png`
